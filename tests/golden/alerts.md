# Alerts

> [!NOTE]
> Both NOTE and IMPORTANT map to the same `info` panel.

> [!TIP]
> Run `docume publish --dry-run` first.

> [!IMPORTANT]
> Approval state lives in labels, never in the page body.

> [!WARNING]
> WARNING maps to the `note` panel, not to `warning`.

> [!CAUTION]
> CAUTION is the one that maps to `warning`.

> [!note]
> A lowercase marker is still an alert on GitHub.

> [!NOTE]
> The panel body keeps every block:
>
> - a list item
> - another item
>
> and a closing paragraph with **bold** text.
