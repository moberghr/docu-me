# Loan service API

## Endpoints

| Method | Path | Notes |
|--------|:----:|------------|
| `GET` | `/loans/{id}` | Returns a **single** loan |
| `POST` | `/loans` | See [the API docs](https://example.com/api?a=1&b=2) |
| `DELETE` | `/loans/{id}` | Escaped pipe a \| b, ampersand a & b |

Column alignment (`:----:`) and the header dash counts are an accepted loss: the
table above renders plain.
