# Mixed Task Lists

A list mixing task and plain items degrades to a plain list; the markers stay as
text so completion state is not lost.

- [x] task item
- regular item
- [ ] another task item

Ordering does not change the rule.

1. [x] shipped
2. still open

A marker that does not open the item is ordinary text, exactly as GitHub renders it.

- mark the box [x] before signing
