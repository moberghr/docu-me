## Assumptions & risks

- **[ASSUMED]** SDK 10.0.100 supports `dotnet new sln --format slnx`. Verified at implementation time; fall back to hand-authored slnx XML if not.
- **[RISK]** `System.CommandLine` 2.0 API changed across betas (`SetHandler` → `SetAction`). Resolve the actual package version, confirm the API from docs before writing `Program.cs`. For `--version` specifically, `RootCommand` provides the option built-in, minimizing API surface used.
- **[ASSUMED]** `TreatWarningsAsErrors` is achievable on a clean scaffold; if template-generated code trips an analyzer, scope the suppression narrowly rather than disabling globally.
